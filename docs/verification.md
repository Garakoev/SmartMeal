## Консольное приложение с PostgreSQL

При запущенном `Sms.DemoServer` выполнены обе команды:

```powershell
.\scripts\Smoke-Test.ps1 -Transport Http
.\scripts\Smoke-Test.ps1 -Transport Grpc
```

Обе завершились с кодом 0 и сообщением **УСПЕХ**. Проверялась последовательность ввода:

1. `UNKNOWN:1` — неизвестный артикул, предложен повторный ввод.
2. `A1004292:0` — неположительное количество, предложен повторный ввод.
3. `A1004292:1;A1004293:0.408` — заказ отправлен успешно.

В локальной БД `sms_test` сохранены два блюда из примера задания. Повторный запуск через второй транспорт не создаёт дубликаты. Пароль подключения хранится только в исключённом из Git `appsettings.local.json` и его локальной копии рядом с собранным приложением.
